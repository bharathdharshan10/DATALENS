# 📊 DataLens — Dynamic CSV Analyzer

### Your Data, Your Insights 🚀

DataLens is a dynamic CSV analysis and visualization web application built with Python. It allows users to upload CSV files, explore datasets, analyze statistics, and visualize data through interactive charts.

## ✨ Features

- 📁 **CSV Upload** — Upload your own CSV datasets.
- 👀 **Data Preview** — Quickly view the first rows of your dataset.
- 📈 **Statistical Analysis** — Explore descriptive statistics.
- 🔍 **Missing Value Detection** — Identify missing values in each column.
- 🔄 **Duplicate Detection** — Find duplicate rows in your dataset.
- 📊 **Data Visualization** — Create Bar, Line, and Scatter charts.
- 🌙 **Dark Theme** — A clean interface for analyzing data.

## 🛠️ Tech Stack

- **Python** — Core programming language.
- **Streamlit** — Web application interface.
- **Pandas** — Data manipulation and analysis.
- **Matplotlib** — Data visualization.
- **uv** — Python package and project management.
